DATA DETECTIVE — GITHUB PAGES

Files:
- index.html       Student lab with responsive assignment sidebar
- app.js           Seeded dataset generator + analysis tools
- style.css        Styling

Quick GitHub Pages setup:
1. Create a new GitHub repository (example: data-detective).
2. Upload all four files to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch.
4. Select the main branch and /(root), then Save.
5. Your student URL will end with /data-detective/.
6. Open the GitHub Pages URL to use the student lab.

Responsive assignment questions:
- On desktop, Parts 1–4 remain available in a sticky right sidebar.
- Each part can be expanded or collapsed independently.
- On smaller screens, use View Assignment Questions to show or hide the panel.
- The disclosure controls are keyboard accessible.

Case behavior:
- Case Codes are normalized to uppercase.
- The same Case Code always generates the same 30 employees.
- It also generates the same planted patterns, influential observation, and verification code.
- No student data is sent to or stored by the page.
